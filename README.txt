AIRFORCE PREP — Study Planner (PWA)

FILES
- index.html: the app
- manifest.json: installable app metadata
- sw.js: offline cache
- icon.svg: app icon

IMPORTANT
- App data is stored locally in the browser on this device.
- Export a backup from Progress before clearing browser data or changing devices.
- To install as a PWA, host these files on an HTTPS site (e.g. GitHub Pages), open the HTTPS URL in Chrome on Android, then use Chrome menu > Add to Home screen / Install app.
- The app is an independent organiser, not an official Indian Air Force app. Verify the latest intake notification for syllabus and marking rules.

QUICK START (GitHub Pages from a phone)
1. Sign in to GitHub or create an account.
2. Create a new public repository, e.g. airforce-prep-planner.
3. Upload all four files from this ZIP to the repository root (not the ZIP itself).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the Pages URL to appear. Open it in Chrome on Android.
7. Chrome menu (⋮) > Add to Home screen or Install app.
8. Open the installed app and start ticking targets.

If GitHub Pages asks for a workflow or the page does not load, check that index.html is in the repository root and Pages is enabled for the main branch.
